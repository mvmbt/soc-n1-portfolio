# 🛡️ Portfólio de Análise de Segurança — SOC N1

Repositório técnico documentando laboratórios práticos de monitoramento, triagem de alertas (*Triage*), análise de tráfego de rede, investigação de logs (Windows/Linux) e *Threat Intelligence*.

## 📂 Estrutura dos Laboratórios e Incidentes

- **`01-Redes/`** — Análise de protocolos TCP/IP, portas críticas, DNS Tunneling, HTTP/HTTPS e captura de pacotes (Wireshark).
- **`02-Logs-e-SIEM/`** — Investigação de força bruta SSH/RDP, Windows Event Viewer, logs Linux e mapeamento MITRE ATT&CK.
- **`03-Phishing-e-OSINT/`** — Análise de cabeçalhos de e-mail (SPF/DKIM/DMARC), extração de IoCs e reputação (VirusTotal, AbuseIPDB, CyberChef).

## 🛠️ Ferramentas Utilizadas
- **Rede & Pacotes:** Wireshark, PowerShell (`netstat`, `nslookup`), DevTools
- **Logs & SIEM:** Windows Event Viewer, Splunk Free, Terminal Linux
- **OSINT & Decodificação:** VirusTotal, AbuseIPDB, URLscan.io, CyberChef, LetsDefend
